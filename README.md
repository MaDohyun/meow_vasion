# BEAM BANDIT

OpenAI Game Builders Seoul 2026 Track 1 출품용 3분 UFO 아케이드 게임입니다.

작고 밀도 높은 도시를 저공 비행하며 하나의 트랙터 빔으로 납치·스캔·차량 파괴 미션을 처리합니다. 미션을 완료할수록 GTA식 수배 별이 오르고, 지상 경찰과 최대 3대의 전투기가 추격합니다. 별 5개에 도달하면 18초를 버텨 탈출해야 합니다.

## 실행

```bash
pnpm install
pnpm dev
```

## 조작

- 마우스: 좌우 선회와 상하 피치. 위로 두면 상승 방향, 아래로 두면 하강 방향
- `W/S`: 현재 바라보는 3D 방향으로 전진·후진
- `A/D`: 좌우 스트레이프 이동
- `E` 유지: 통합 트랙터 빔
- `Q` 유지: 레이저
- `Space` 유지: 터보 (사용 중 빔 비활성)

빔은 고도와 관계없이 `E`를 누르면 표시되지만, 높은 곳에서는 지상 목표를 잠글 수 없습니다. 저공에서 멈춰 7초간 몸을 숨기면 수배 별을 하나 낮출 수 있고, 8초간 피격되지 않으면 3칸 실드가 복구됩니다.

## 게임 루프

1. 초록·하늘색·노란 표식으로 표시된 미션 대상을 찾습니다.
2. 낮게 접근해 `E` 빔을 유지합니다.
3. 빠르게 다음 미션을 완료해 체인 배수를 올립니다.
4. 별이 오르면 낮게 숨어 경찰을 떼거나, 고공 터보로 이동하며 전투기와 싸웁니다.
5. 별 5개에서 18초 생존하거나 3분을 버티면 레이드가 끝납니다.

## 검증

```bash
pnpm test
pnpm build
pnpm smoke
```

핵심 미션 로직은 `src/core/missions.ts`, 런타임 규칙은 `src/GameContext.tsx`, 3D 표현은 `src/render/DroneScene.tsx`에 있습니다.
