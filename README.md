# BEAM BANDIT

OpenAI Game Builders Seoul 2026 Track 1 출품용 오픈 런 UFO 아케이드 게임입니다.

600×600 기본 도시 타일을 상하좌우로 무한 순환하며 트랙터 빔으로 납치·스캔·차량 파괴 미션을 처리합니다. UFO와 카메라의 월드 좌표는 텔레포트하지 않고 연속으로 유지되며, 같은 도시 데이터의 3×3 렌더 복제본이 플레이어를 따라 재배치됩니다. 미션을 완료할수록 GTA식 수배 별이 오르고, 지상 경찰과 최대 3대의 전투기가 추격합니다.

첫 실행에서는 프리플라이트 로딩 화면이 절차적 도시 텍스처·폰트·셰이더와 첫 렌더 프레임을 미리 준비합니다. 플레이 중에는 카메라에 들어온 토러스 타일과 도시 구역만 활성화하며, 차량은 가시 복제본만 인스턴스 렌더링합니다.

## 실행

```bash
pnpm install
pnpm dev
```

## 조작

- 마우스: 좌우 선회와 상하 피치. 위로 두면 상승 방향, 아래로 두면 하강 방향
- `W/S`: 현재 바라보는 3D 방향으로 전진·후진
- `A/D`: 오른쪽/왼쪽 스트레이프 이동
- `E` 유지: 미션 대상과 주변 차량을 끌어당기는 트랙터 빔
- `Q` 유지: 마우스 포인터 방향 레이저
- `Space` 유지: 터보
- `Space + E`: 고속에서도 차량 무리를 잡는 확장·강화 빔

차량은 빔 원뿔 안에서 UFO의 속도를 강하게 따라오고, 원뿔이나 최대 거리 밖으로 나가는 즉시 빔에서 이탈해 중력으로 떨어집니다. 저공에서 멈춰 7초간 몸을 숨기면 수배 별을 하나 낮출 수 있고, 8초간 피격되지 않으면 3칸 실드가 복구됩니다.

## 게임 루프

1. 초록·하늘색·노란 표식으로 표시된 미션 대상을 찾습니다.
2. 낮게 접근해 `E` 빔을 유지합니다.
3. 빠르게 다음 미션을 완료해 체인 배수를 올립니다.
4. 별이 오르면 낮게 숨어 경찰을 떼거나, 고공 터보로 이동하며 전투기와 싸웁니다.
5. 별 5개에서 18초 생존해 탈출할 때까지 원하는 만큼 도시를 누빕니다.

일반 최고 속도는 24, 터보 최고 속도는 42이며 최대 고도는 90입니다. 토러스 최단 거리 계산 때문에 경계 반대편의 미션·차량·충돌 지형도 바로 이웃처럼 동작합니다.

HUD 시간은 제한 시간이 아니라 현재 런의 경과 시간입니다. 원경 스카이라인은 드론의 월드 셀과 시선 구역을 기준으로 최대 40개 블록만 결정론적으로 인스턴스 렌더링합니다.

## 검증

```bash
pnpm test
pnpm build
pnpm smoke
```

토러스 좌표와 충돌은 `src/core/torus.ts`, 차량 빔 물리는 `src/core/beam.ts`, 런타임 규칙은 `src/GameContext.tsx`, 3D 표현은 `src/render/DroneScene.tsx`에 있습니다.
