# 침략할거냥 (Meowvasion)

도시를 파괴하면서 최대한 오래 살아남는 절차적 UFO 아케이드 게임입니다. 45초에서 시작하는 생존 시간이 계속 줄어들며, 보행자와 고양이를 빔으로 흡수하면 시간이 늘어납니다. 180초 누적 생존에 성공하고, 시간이 0이 되면 실패합니다. 목숨 제한은 없습니다.

## 실행

```bash
pnpm install
pnpm dev
```

## 조작

- 마우스: 캔버스 기준 조준·선회·상하 피치
- `W/S`: 보는 방향으로 전진·후진
- `A/D`: 좌우 스트레이프
- `E` 유지: 트랙터 빔. 보행자·고양이는 흡수해 시간을 얻고, 자동차는 끌어옵니다.
- `Q` 유지: 마우스 조준점으로 레이저 연속 발사
- `Space`: 부스터. 빔과 동시에 사용할 수 있습니다.
- `R`: 끌어온 자동차를 비상 투하

자동차는 최대 6대까지 화물로 연결되며, 화물이 많을수록 UFO 속도가 느려집니다. 빔 원뿔이나 사거리에서 벗어난 오브젝트는 즉시 떨어집니다. 점수는 자동차 파괴·적 격추 같은 이벤트로만 증가하며 생존 시간에 따라 감소하지 않습니다.

## 화면 구성 (HUD)

정보를 한 곳에 몰아 다섯 덩어리로만 읽습니다. 화면 여기저기에 떠 있던 카드는
모두 이 다섯 중 하나에 들어갑니다.

- **왼쪽 위 — 생존과 목표**: 하트(선체)와 미션 목록. 미션은 항목마다 아이콘이
  붙어 문장을 읽기 전에 어떤 목표인지 먼저 눈에 들어옵니다.
- **가운데 위 — 런 상태**: 점수와 남은 시간. 항상 표시됩니다. 공중전함 체력바,
  과적·호수 경보, 미션 단계 배너도 이 열에 차례로 쌓이므로 서로 겹치지 않습니다.
- **오른쪽 위 — 조작법**: 판이 시작되면 잠깐 떴다가 접히고, 그 자리에 남는 `?`
  버튼으로 언제든 다시 열 수 있습니다. 이동·조준뿐 아니라 `E` 빔과 `Q` 레이저도
  함께 적혀 있습니다.
- **왼쪽 아래 — 레이더**: 적, **호수(물 타일)**, 미스터리 서클, 목표 방향을
  기수 기준으로 표시합니다. 색만 있는 범례 대신 이름을 붙였습니다.
- **가운데 아래 — 기체 상태**: 질량, 터보 게이지, 항력 게이지와 그것들을 움직이는
  키(`E`·`Q`·`SPACE`)를 한 카드에 모았습니다.
- **오른쪽 아래 — 파일럿**: 표정이 그대로 상태 표시이므로 얼굴은 판 내내 떠
  있고, 흡수·격추·픽업 같은 알림이 있을 때만 얼굴 위에 말풍선이 뜹니다.

## 게임 루프

1. 남은 생존 시간을 확인합니다.
2. `E`로 사람과 고양이를 흡수해 시간을 확보합니다. 고양이는 더 많은 시간을 줍니다.
3. 자동차를 묶어 이동하거나 `Q` 연속 레이저로 파괴해 점수를 얻습니다.
4. 생존 시간이 흐를수록 자폭 드론 기뢰→헬기→전투기→대공망→공중전함 순서로 웨이브가 격상되므로 부스터와 고도 선택으로 공격을 피합니다.
5. 180초 누적 생존을 달성합니다.

적 웨이브는 경과 시간에만 묶여 있습니다. 웨이브는 여섯 단계이고 한 단계가 한 종류를 데려오며, 뉴스 속보 한 건이 그 종류를 알립니다. 자폭 드론은 전부 공중에 정지한 기뢰라 쫓아오지 않고, 붉은 폭발 반경 안에 들어가면 0.3초 뒤 터집니다. 헬기는 자기 고도 대역을 지키며 지나가고, 전투기는 무작위 근처 지점을 향해 스쳐 지나갑니다. 대공포는 건물 옥상에 고정돼 고도 28m 위만 조준하며, 공중전함은 거리를 유지하면서 예고 후 함포를 발사합니다. 대공포와 공중전함은 빔으로 흡수할 수 없습니다.

건물과 도로는 좌표 해시 기반으로 재생성되고, 플레이어 주변 풀만 활성화됩니다. 렌더링은 InstancedMesh와 고정 슬롯을 사용하며, 초기 로딩 화면에서 셀 풀·셰이더·카메라를 준비합니다. 로비에서는 제공된 MP3 BGM을 반복 재생하고, 게임 시작과 함께 정지합니다. 게임 BGM은 아주 낮은 볼륨에서 시작해 8초 동안 효과음 아래의 볼륨으로 올라가며, 결과 화면에서 멈춥니다.

## 랭킹 · 구글 스프레드시트 연동

게임 오버 화면에서 **랭킹 등록**을 누르고 이름을 적으면 이번 판의 점수·생존
시간·웨이브가 구글 스프레드시트에 한 줄로 기록되고, 바로 아래 순위표에 내 줄이
강조되어 나타납니다. 순위는 점수 → 생존 시간 → 먼저 기록한 순서로 매겨집니다.

시트를 연결하지 않아도 버튼은 동작합니다. 이때 기록은 이 브라우저에만 저장되며
순위표에 "시트가 연결되지 않아 이 브라우저에만 저장했습니다"라고 표시됩니다.

### 연결하는 법

1. 구글 스프레드시트를 새로 만듭니다. 시트 이름은 그대로 두어도 됩니다.
   (`ranking` 시트는 첫 기록이 들어올 때 헤더와 함께 자동으로 만들어집니다.)
2. 그 시트에서 **확장 프로그램 → Apps Script**를 엽니다.
3. `google-apps-script/Code.gs`의 내용을 전부 복사해 편집기에 붙여넣고
   저장합니다.
4. **배포 → 새 배포 → 유형: 웹 앱**을 선택하고 다음과 같이 설정합니다.
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. 배포하면 나오는 `https://script.google.com/macros/s/.../exec` URL을 복사합니다.
   `/dev`로 끝나는 주소는 본인만 열 수 있으므로 쓰지 않습니다.
6. 저장소 루트에 `.env`를 만들고 그 URL을 넣습니다. (`.env.example` 참고)

   ```
   VITE_LEADERBOARD_URL=https://script.google.com/macros/s/.../exec
   ```

7. `pnpm dev`를 다시 시작합니다. Vite는 환경 변수를 빌드 시점에 읽으므로
   개발 서버와 배포 빌드 모두 다시 실행해야 반영됩니다.

`Code.gs`를 고친 뒤에는 **배포 → 배포 관리**에서 기존 배포의 버전을 새로
올려야 합니다. 새 배포를 만들면 URL이 바뀌어 `.env`도 함께 고쳐야 합니다.

### 공개할 때 알아둘 것

이 방식은 서버 없는 정적 게임이 쓸 수 있는 구조라 태생적인 한계가 있습니다.
막아 둔 것과 막을 수 없는 것을 나눠 적습니다.

**막아 둔 것**

- 이름은 화면에 글자로만 그려집니다. React가 escape하므로 `<script>` 같은
  이름을 적어도 코드로 실행되지 않습니다.
- 이름은 시트에 **수식이 아니라 글자로** 저장됩니다. `=`, `+`, `-`, `@`로
  시작하는 이름을 그대로 넣으면 남이 적은 글자가 내 시트에서 살아 있는 셀이
  되는데, 그렇게 되지 않도록 강제합니다.
- 눈에 보이지 않는 문자(zero-width, 방향 뒤집기)는 지웁니다. 순위표의 줄이
  이상하게 뒤집히거나 빈 줄로 보이는 일을 막습니다.
- 로그는 `MAX_STORED_ROWS`(기본 2000줄)로 묶여 있습니다. 장난으로 수천 건을
  밀어 넣어도 시트가 무한히 커지거나 새 기록이 순위에서 밀려나지 않습니다.
- 점수·생존 시간·웨이브에 천장이 있습니다. 값을 지어내도 `9999999999` 같은
  숫자가 1위에 박혀 순위표 자체를 못 쓰게 되는 일은 없습니다.
- 같은 기록이 두 번 전송되어도 행은 하나만 남습니다.
- 게임이 보내는 것은 이름·점수·생존 시간·웨이브·승패·기록 시각뿐입니다.
  IP, 이메일, 기기 정보는 보내지 않습니다.

**막을 수 없는 것 (구조상)**

- **점수는 위조할 수 있습니다.** 웹 앱 주소는 빌드 결과물에 그대로 들어 있고,
  숨겨도 브라우저 개발자 도구로 몇 초면 찾습니다. 즉 게임을 하지 않고도
  아무 이름과 점수를 보낼 수 있습니다. 천장 덕분에 "그럴듯한 점수"까지만
  올라가지만, 가짜 1위 자체를 막으려면 점수를 검증하는 진짜 서버가 필요합니다.
  친구들끼리 하는 순위표라면 충분하고, 상금이 걸린 대회라면 부족합니다.
- **누구나 기록을 보낼 수 있으니 아무 이름이나 올라올 수 있습니다.** 욕설이
  올라오면 시트에서 그 줄을 지우면 됩니다.
- **할당량은 소진될 수 있습니다.** Apps Script에는 하루 실행 한도가 있어,
  누군가 요청을 계속 보내면 그날 순위표가 동작하지 않을 수 있습니다. 다음 날
  자동으로 풀립니다.
- **CSV로 내려받아 엑셀에서 열 때는 주의하세요.** 시트 안에서는 이름이 글자로
  묶여 있지만 CSV로 빠져나가면 그 표시가 사라집니다. 이름이 12자로 잘려 있어
  의미 있는 수식이 들어갈 자리가 없다는 점이 실질적인 방어선이므로,
  `NAME_MAX_LENGTH`를 늘릴 생각이라면 이 점을 같이 따져보세요.

**설정할 때 지킬 것**

- **랭킹 전용 스프레드시트를 새로 만들어 쓰세요.** 웹 앱은 "나"의 권한으로
  실행되고 자기가 붙어 있는 스프레드시트를 건드립니다. 다른 자료가 들어 있는
  시트에 붙이지 마세요.
- 이 스크립트에 다른 권한(Gmail, Drive 등)을 쓰는 코드를 덧붙이지 마세요.
  덧붙이는 순간 그 권한도 익명 요청에 열립니다.
- 플레이어에게 실명·연락처를 적게 유도하지 마세요. 시트에 남는 이름은 순위표를
  보는 모두에게 공개됩니다.

이 URL은 정적 빌드에 그대로 포함되므로 비밀이 아닙니다. 접근 제어는 URL을
감추는 것이 아니라 Apps Script 배포 설정이 맡습니다.
