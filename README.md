# BEAM BANDIT

OpenAI Game Builders Seoul 2026 Track 1 출품용 오픈 런 UFO 아케이드 게임입니다.

좌표 해시로 결정되는 무한 절차 도시를 어느 방향으로든 계속 비행하며 트랙터 빔으로 납치·스캔·차량 파괴 미션을 처리합니다. 34×34 셀은 같은 좌표에서 항상 같은 건물·차량·도로를 만들고, 경계나 좌표 래핑 없이 플레이어 주변 셀만 활성화합니다. 미션을 완료할수록 GTA식 수배 별이 오르고, 지상 경찰과 최대 3대의 전투기가 추격합니다.

첫 실행에서는 프리플라이트 로딩 화면이 절차적 도시 텍스처·사인 아틀라스·셰이더와 첫 렌더 프레임을 미리 준비합니다. 플레이 중에는 생성 250/제거 300유닛 히스테리시스로 절차 건물·주차 차량을 활성화하고, 별도의 주행 차량 16슬롯과 레이저 투사체 18슬롯을 포함한 고정 인스턴스 풀을 재사용합니다.

## 실행

```bash
pnpm install
pnpm dev
```

## 조작

- 마우스: 좌우 선회와 상하 피치. 위로 두면 상승 방향, 아래로 두면 하강 방향
- `W/S`: 현재 바라보는 3D 방향으로 전진·후진
- `A/D`: 오른쪽/왼쪽 스트레이프 이동
- `E` 유지: 미션 대상과 주변 차량을 끌어당기는 트랙터 빔
- `Q` 한 번: 바라보는 방향으로 레이저 투사체 한 발 발사
- `Space` 유지: 터보
- `Space + E`: 고속에서도 차량 무리를 잡는 확장·강화 빔

주차 차량과 도로를 달리는 차량은 빔 원뿔 안에서 UFO를 따라오며, 원뿔이나 최대 거리 밖으로 나가는 즉시 빔에서 이탈해 중력으로 떨어집니다. 자동차 질량은 2.4라 가벼운 미션 대상보다 눈에 띄게 천천히 상승합니다. 저공에서 멈춰 7초간 몸을 숨기면 수배 별을 하나 낮출 수 있습니다. 현재 버전에는 목숨 제한이 없으며 충돌·피격은 반동과 연출만 발생시킵니다.

## 게임 루프

1. 초록·하늘색·노란 표식으로 표시된 미션 대상을 찾습니다.
2. 낮게 접근해 `E` 빔을 유지합니다.
3. 빠르게 다음 미션을 완료해 체인 배수를 올립니다.
4. 별이 오르면 낮게 숨어 경찰을 떼거나, 고공 터보로 이동하며 전투기와 싸웁니다.
5. 별 5개에서 18초 생존해 탈출할 때까지 원하는 만큼 도시를 누빕니다.

일반 최고 속도는 30, 터보 최고 속도는 54이며 최대 고도는 130입니다. 월드에는 경계가 없고, 이동할 때 주변 건물 콜라이더와 주차 차량 풀만 결정론적으로 교체됩니다. 주행 차량만 시야 밖 도로에서 비결정론적으로 생성됩니다.

HUD 시간은 제한 시간이 아니라 현재 런의 경과 시간입니다. 원경 스카이라인은 55유닛 월드 셀에 고정된 블록 중 드론에서 280~340유닛 밴드에 들어온 것만 최대 72개까지 인스턴스 렌더링합니다. 이동해도 기존 블록은 자리를 바꾸지 않습니다. 실시간 그림자는 쓰지 않고 건물·차량 바닥의 인스턴스 blob shadow로 깊이감만 유지합니다.
